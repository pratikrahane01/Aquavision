# AquaVision YOLO11n - Model Performance & Evaluation Metrics

This document details the quantitative and qualitative evaluation results of the **AquaVision YOLO11n** object detection model trained on river surface waste imagery.

---

## 1. Executive Summary

AquaVision leverages the lightweight **YOLO11n** (Nano) architecture to detect and classify river-borne litter in real time. Following a rigorous 100-epoch training schedule across approximately 10,000 annotated images (expanded to 18,635 images via robust domain-specific data augmentations), the model achieved high precision and recall on the held-out validation set.

### Overall Performance Scores

| Metric | Score (Decimal) | Score (Percentage) |
|---|:---:|:---:|
| **Precision (P)** | `0.9774` | **97.74%** |
| **Recall (R)** | `0.9483` | **94.83%** |
| **mAP@50 (IoU = 0.50)** | `0.9788` | **97.88%** |
| **mAP@50-95 (IoU = 0.50:0.95)** | `0.7306` | **73.06%** |
| **F1-Score** | `0.9627` | **96.27%** |

*Note: All evaluation scores reflect standard validation with IoU threshold 0.45 and confidence threshold 0.25 on held-out validation samples.*

## 2. Detection Classes & Taxonomy

The model recognizes five discrete classes of river pollutants defined in `data.yaml`:

| Class ID | Class Name | Description | Key Visual Characteristics |
|:---:|:---|:---|:---|
| `0` | **`can`** | Metal beverage cans, tin containers, aluminum cans | Cylindrical, metallic reflections, floating upright or sideways |
| `1` | **`foam`** | Expanded polystyrene (EPS) foam, thermocol packing pieces | Bright white, irregular fragmented shapes, high surface buoyancy |
| `2` | **`plastic`** | General plastic waste, polybags, wrappers, sheets, sacks | Flexible, partially translucent/crumpled, semi-submerged edges |
| `3` | **`plastic bottle`** | PET plastic bottles, drink containers | Cylindrical/tapered neck, transparent or tinted, air-trapped buoyancy |
| `4` | **`unknow`** | Miscellaneous / unidentified floating aquatic debris | Debris with mixed material properties or partial occlusions |

---

## 4. Key Performance Observations

1. **High Discrimination between Plastic vs. Foam**: Despite both floating on water surfaces, the model separates expanded polystyrene (`foam`) from smooth PET bottles (`plastic bottle`) and sheet debris (`plastic`) with negligible misclassification.
2. **Robustness to Aquatic Environmental Factors**:
   - Resilience against specular sun glares, light glints, and surface ripple patterns.
   - Robust detection under variable water turbidity, murky riverbeds, and partial shadow occlusions.
3. **Edge Optimization**:
   - Model weight footprint: **~5.5 MB** (`best.pt`).
   - Inference latency: ~2-5 ms on modern CUDA GPUs, ~20-35 ms on mobile/CPU architectures, enabling 30+ FPS edge deployment.
